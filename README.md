##  Projeto em desenvolvimento

###  Portal de Gestão da Catequese — Comunidade São José Operário
Sistema web para gestão e controle de presença de catequese, com autenticação,
controle de acesso por papéis (admin, coordenador, catequista) e acompanhamento
de frequência mínima dos alunos.

- **Stack:** Next.js 15 (App Router), Tailwind CSS, Supabase (PostgreSQL + Auth)
- **Arquitetura:** RBAC, gestão de turmas/alunos, registro de frequência
